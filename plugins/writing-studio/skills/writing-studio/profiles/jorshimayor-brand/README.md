# Marked j: vector master

Every shape is a filled path (no strokes, no live text, no transforms). The wordmark is outlined from Bricolage Grotesque 96pt ExtraBold (SIL Open Font Licence) with the font's own kerning and the brand's −0.03 em tracking; the source font and the build script live in the author's design folder, so the files open cleanly in Figma, Illustrator or Inkscape and scale to any size. Drawn on a 64-unit grid; the favicon is redrawn on a 16-unit grid.

| File | Use |
|---|---|
| `mark-colour-on-paper.svg` | Default: light backgrounds |
| `mark-colour-on-ink.svg` | Dark backgrounds: paper j, ink where it crosses the highlighter, lighter red ring (#ff6b81) |
| `mark-auto.svg` | Web: switches between the two with the viewer's light or dark setting |
| `mark-paper-tile.svg`, `mark-ink-tile.svg` | App icons and avatars: the mark on a rounded paper or ink square |
| `mark-mono-ink.svg`, `mark-mono-paper.svg` | Single colour: one ink, the j knocked out where it crosses the swipe. For stamps, embossing, merch, single-colour print |
| `mark-mono-ink-tile.svg` | Single colour on a tile |
| `favicon-16.svg`, `favicon-16-dark.svg`, `favicon.svg` | Favicon redrawn for 16 px: thicker j, no ring, the dot itself in marker red. `favicon.svg` follows light or dark mode |
| `favicon.ico` | 16, 32 and 48 px for older browsers |
| `lockup-horizontal-*.svg` | Mark beside the wordmark: on-paper, on-ink, mono-ink, mono-paper. The wordmark's baseline sits at the end of the j's stem |
| `lockup-stacked-*.svg` | Mark centred above the wordmark, same four versions. For square spaces and covers |
| `wordmark-*.svg` | The wordmark alone, same four versions |


Colours: ink #0b0b0b, paper #fcfcfb, ink tile #141413, highlighter #ffe45c, marker red #d1203f (light) and #ff6b81 (dark).

Clear space: keep at least the dot's diameter (11 units) clear on every side. Minimum size: 24 px for the full mark; below that, use the favicon drawing.
